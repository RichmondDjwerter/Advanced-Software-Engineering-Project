## Requirements
- Node.js >= 26.8.2
- npm >= 12.0.2

## Installing and deploying project locally
1. Git clone the project
2. Run the following commands at the root of the folder `my-app`:
    ```
    npm install
    npm run build
    npm run start
    ```

3. Check if the server is running locally by following this URL: http://localhost:3000/

## Technology stack
- Full-stack React framework with Next.js
